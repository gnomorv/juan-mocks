# Clara Studio mock-ups

Juan Arce's collection of front-end mock-ups for Clara Studio, served with GitHub Pages. These are working proposals, not a team convention or decided standards.

**Live:** https://gnomorv.github.io/juan-mocks/

| Mock-up | Path | Notes |
|---|---|---|
| Help site FAQ | [/help-site-faq/](https://gnomorv.github.io/juan-mocks/help-site-faq/) | FAQ page for the Clara Learning help site with Docusaurus `<details>` collapsibles; placeholder content |
| Documents navigation | [/documents-navigation/](https://gnomorv.github.io/juan-mocks/documents-navigation/) | Return to the folder you opened a document from; current vs proposed for workspace and project documents |
| Documents tree view | [/documents-tree-view/](https://gnomorv.github.io/juan-mocks/documents-tree-view/) | Documents tab as one foldable tree for the library, a workspace and a project. Moved from the retired clara-documents-mockups repo |
| Global search | [/global-search/](https://gnomorv.github.io/juan-mocks/global-search/) | Concept: search page and ⌘K search bar |
| Workspace and project detail | [/clara-1262-detail-redesign/](https://gnomorv.github.io/juan-mocks/clara-1262-detail-redesign/) | One layout for both pages; Clara-1262 |
| Stage requirements stepper | [/clara-1072-stage-requirements/](https://gnomorv.github.io/juan-mocks/clara-1072-stage-requirements/) | Shipped in Clara-1072 |
| MVP chat with Clara | [/mvp-chat/](https://gnomorv.github.io/juan-mocks/mvp-chat/) | Concept: the first chat MVP |
| Studio shell | [/studio-shell/](https://gnomorv.github.io/juan-mocks/studio-shell/) | Concept: early app shell with a floating chat |

Each mock-up lives in its own folder with an `index.html`, and follows the review format in [`PAGE-FORMAT.md`](PAGE-FORMAT.md): Current / Proposed / Side by side, Light / Dark, and numbered notes on what changed and why. The shared styles and script in `assets/` are copied from Luciana Oliveira's mock-ups so both collections look the same. To add one, create a folder, put the page in it as `index.html`, and add a card to the root `index.html` and a row to this table. All data is synthetic.

What ADP is made of

  • What ADP is: the Autonomous Dev Pipeline.
  • What defines it: 24 documents and 11 skills.
  • What is not counted: about 900 more documents in its project. They are records of individual runs, not part of the definition.
  • When it was counted: November 20, 2026.

Each document name is a link (↗) that opens the document in Clara Studio. A sign-in with access to the project is required. A skill has no address of its own: all skills open from the Skills screen ↗ in the Admin console.

1Skills 11Open the Skills screen ↗

A skill is a written set of instructions for one stage of the pipeline, such as planning an issue or opening a pull request. When an agent starts that stage, Clara Studio sends it the skill's text and the agent follows it step by step.

To read a skill: click its name below, find it in the list on the Skills screen, and choose Edit. Nothing changes unless you save.

How to read this

ADP lives almost entirely in documents and skills, not in code. This page separates what defines it from what it produces while running.

  1. Skills are what an agent runs. Eleven stages, from setup to backlog. A stage follows only its own text and the documents it cites.
  2. ADP reference documents are the rulebook. Fourteen documents the skills cite. Changing a rule means editing one of these, not a skill.
  3. Run history is output, not definition. About 900 documents record individual runs. Counting them would make ADP look 25 times larger than it is.
  4. Most of it is still draft. Four of the 24 documents are approved. Anything built on these rules should expect them to move.

What ADP is made of

ADP, the Autonomous Dev Pipeline, is defined by 24 documents and 11 skills. Its project holds about 900 more documents, but those are records of individual runs, not part of the definition. Counted on November 20, 2026.

Each document name is a link (↗) that opens the document in Clara Studio. A sign-in with access to the project is required. Skills have no page of their own, so they are not linked.

How to read this

ADP lives almost entirely in documents and skills, not in code. This page separates what defines it from what it produces while running.

  1. Skills are what an agent runs. Eleven stages, from setup to backlog. A stage follows only its own text and the documents it cites.
  2. Reference documents are the rulebook. Fourteen documents the skills cite. Changing a rule means editing one of these, not a skill.
  3. Run history is output, not definition. About 900 documents record individual runs. Counting them would make ADP look 25 times larger than it is.
  4. Most of it is still draft. Four of the 24 documents are approved. Anything built on these rules should expect them to move.

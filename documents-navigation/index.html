What changed and why

Today, leaving a document always lands on the workspace or project Overview, so people reopen Documents and find their folder again every time. The proposal keeps the tab and the folder in the links. Try it: pick Workspace or Project in the bar, open a document inside a folder, then get back to the folder or open the next document. The strip above each app shows the address and counts your clicks. Both views share one layout; the proposed one uses the shared proposed type roles, so only the navigation differs.

  1. "Back to <folder>" sits above the document title. It reads "Back to 2. Design", or "Back to Documents" at the root, and opens the Documents tab at that folder. Today a document has no way back; the breadcrumb is the only way out. The link also works on phones, where the breadcrumb is cut down to the current page.
  2. The breadcrumb names Documents and each folder. Acme Corp › Website Rebuild › Documents › 2. Design › Solution Design. Each part opens Documents at that level, and the workspace or project crumb returns to the same tab instead of Overview. Root cause: today the breadcrumb links to /w/<slug> and /p/<id> without ?tab=documents, so it always opens Overview. The document page knows its folder but never shows it.
  3. The open folder is kept in the address. As you move between folders the address gains &folder=…, so browser Back, refresh and shared links reopen the same folder. Root cause: today the open folder lives only in the Documents list's own memory (component state in ArtifactExplorer), never in the address. It resets whenever the list leaves the screen, so even browser Back lands at the root. Compare with the arrows in the address strip.
  4. Previous and next in this folder (optional). Links under the document to its neighbours in the same folder, with "2 of 3 in 2. Design". Reading a set of files in order takes one click per file instead of a round trip through the list.
  5. The same return works from every tab. An item opened from Issues, Conversations, Activity, Agreements, Connectors, Assets or the Overview's recent documents shows "Back to <tab>" and a crumb for that tab. The item link carries where it was opened from as ?from=<owner>~<tab>~<folder>. Today every item page has the same dead end as documents.
  6. The row you opened is highlighted when you return. A short blue flash marks it, and the list scrolls to it (the pin shows after you come back). You see where you left off without scanning the list.
  7. Clicks to open the next document.
